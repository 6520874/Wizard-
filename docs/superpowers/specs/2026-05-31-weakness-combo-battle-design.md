# 弱点连携战斗设计

## 目标

在现有回合制战斗和技能框架上加入“巫师味”的轻量弱点连携。玩家能识破怪物弱点，用火焰、雷霆和银剑形成明确的小循环，而不引入战前准备、剑油、炸弹或完整怪物图鉴。

## 第一版范围

- 每个敌人拥有 1-3 个弱点标签。
- 未识破弱点在 HUD 中显示为 `???`。
- `猎魔专注` 揭示首个存活敌人的一个隐藏弱点，并施加 `已标记`。
- `火焰法印` 命中弱火目标时追加伤害并施加 `灼烧`。
- `雷霆法印` 命中导电、灼烧或已标记目标时追加伤害，并施加短暂 `麻痹`。
- `连续斩杀` 命中灼烧、麻痹或已标记目标时追加处决伤害。
- 战斗 HUD 在敌人名牌、技能按钮和战斗提示中展示弱点连携信息。
- 现有回合顺序、奖励、药剂、防御、逃跑和技能特效继续可用。

## 暂不处理

- 战前装备选择、剑油、炸弹和怪物图鉴。
- 手动选择攻击目标。
- 敌人高级 AI 技能。
- 新图片资源和新 Sprite Sheet。
- 复杂抗性、免疫、元素数值表。

## 核心玩法

玩家形成“识破/观察 -> 制造异常 -> 银剑收尾”的节奏：

1. 战斗开始后敌人名牌显示部分弱点，隐藏弱点显示为 `???`。
2. 玩家可以直接尝试火焰、雷霆或连斩，也可以先用 `猎魔专注` 揭示弱点并标记目标。
3. 火焰负责压制弱火目标并制造 `灼烧`。
4. 雷霆负责惩罚导电、灼烧或已标记目标，并制造 `麻痹`。
5. 连续斩杀负责对异常或标记目标追加处决伤害，帮助收尾。

这个循环让玩家不用记复杂表格，也能自然读懂“先看弱点，再用对应技能打连携”。

## 敌人弱点

弱点根据现有 `TurnBasedEnemyVisualKind` 初始化：

- 腐化狼：`弱火`、`怕银剑`。
- 吸血女妖：`导电`、`怕银剑`。
- 月夜骑士：`弱火`、`导电`、`怕银剑`，默认隐藏更多弱点。

第一版不把弱点暴露成 Inspector 配置，避免改动遭遇配置面板。后续如果怪物类型变多，再把弱点迁移到数据表或 ScriptableObject。

## 数据模型

新增小型战斗数据结构：

- `MonsterWeaknessKind`：`Fire`、`Lightning`、`Silver`。
- 敌人状态中保存弱点列表、已识破数量、`Burning`、`Paralyzed`、`Marked` 等战斗标签。
- `TurnBasedEnemyState` 继续是当前战斗敌人的权威状态，HUD 只读取它，不自己推导弱点或连携。

现有 `SkillDefinition` 和 `SkillExecutor` 保持通用。弱点连携逻辑放在 `TurnBasedBattleManager` 附近的专用 helper 中：技能先按现有规则结算，再根据技能 ID、目标弱点和目标状态追加连携结果。

## 技能变化

### 火焰法印

基础效果保持全体火焰伤害。命中弱火目标时追加伤害并施加 `灼烧`。灼烧在第一版只作为连携状态，不做每回合扣血，避免状态结算面扩大。

### 雷霆法印

基础效果保持单体两段雷电伤害。命中导电、灼烧或已标记目标时追加伤害，并施加 `麻痹`。麻痹第一版用于降低该敌人下一次攻击威胁或延后行动，不做完全跳过回合。

### 连续斩杀

基础三连击保持。命中灼烧、麻痹或已标记目标时追加处决伤害；若目标低血量，追加伤害更明显。该技能仍自动攻击第一个存活敌人。

### 猎魔专注

从单纯攻击 Buff 调整为：揭示首个存活敌人的一个隐藏弱点，施加 `已标记`，并保留轻量攻击提升。标记会强化下一次弱点命中和连续斩杀。

## HUD 表现

不重做战斗界面，只增强已有元素：

- 敌人名牌显示弱点标签：`弱火`、`导电`、`怕银剑`，隐藏弱点显示 `???`。
- 敌人名牌显示状态标签：`灼烧`、`麻痹`、`已标记`。
- 技能面板显示一行固定连携提示：
  - 连续斩杀：`标记/异常：追加处决`
  - 火焰法印：`弱火：灼烧`
  - 雷霆法印：`导电/灼烧：麻痹`
  - 猎魔专注：`识破 + 标记`
- 战斗消息在触发连携时说明原因，例如“火焰命中弱点，腐化狼陷入灼烧”。

## 组件职责

### `TurnBasedBattleManager`

- 初始化敌人弱点。
- 在玩家技能结算后应用弱点连携。
- 维护敌人的临时连携状态。
- 生成 HUD 可读的弱点和状态文本。

### `TurnBasedBattleHud`

- 渲染敌人弱点和状态标签。
- 渲染技能按钮上的连携提示。
- 播放现有技能特效，不决定连携结果。

### `WitcherSkillBook`

- 保持技能定义入口。
- 只调整 `HunterFocus` 的基础描述和效果。
- 不承担怪物弱点判定。

### `SkillExecutor`

- 保持通用技能执行器职责。
- 不知道怪物弱点和 HUD 表现。

## 测试策略

优先覆盖不依赖 Unity 场景的逻辑：

- 敌人按视觉类型初始化正确弱点。
- `猎魔专注` 揭示隐藏弱点并施加标记。
- 火焰命中弱火目标会追加伤害并施加灼烧。
- 雷霆命中导电、灼烧或标记目标会追加效果。
- 连续斩杀命中异常或标记目标会追加处决伤害。
- 未命中弱点时技能仍按现有基础效果结算。

视觉部分通过 C# 编译和手动进入战斗验证：弱点标签不重叠，技能按钮提示可读，现有特效正常播放。

## 成功标准

- 玩家能在 HUD 上看出怪物弱点或未知弱点。
- 玩家能通过 `猎魔专注` 获得明确的下一步目标。
- 至少火焰、雷霆、连斩三条连携都能在一场战斗里看见。
- 现有战斗流程没有回归：回合顺序、伤害数字、胜利奖励、药剂和防御仍可用。
- 新逻辑有编辑器测试覆盖，项目能通过 C# 编译。
