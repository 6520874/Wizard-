# Pixel Raid

A small 2D pixel-style platformer prototype for Unity 2022.3.

## How to run

1. Open the project in Unity.
2. Wait for scripts to compile and packages to refresh.
3. Run `Tools/Pixel Raid/Create Playable Scene`.
4. Open `Assets/Scenes/PixelRaidDemo.unity` if Unity does not switch automatically.
5. Press Play.

## Controls

- `A` / `D` or arrow keys: move
- `J` or left mouse button: sword slash

The Wild Hunt boss spawns a short moment after the scene starts. Slash him at close range to trigger his hit reaction; if he reaches you, his attack triggers Geralt's hit reaction.
